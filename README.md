# Steer

Steer is a self-hosted spending notification app.

It watches purchases, sends Telegram push notifications, and explains how each purchase affects the monthly budget.

## Project Layout

- `backend/`: Go API, Telegram bot integration, SQLite storage, and budget logic
- `frontend/`: Vite + React UI for viewing and managing the app

## Status

This project is still in progress, so the docs stay intentionally brief for now.
